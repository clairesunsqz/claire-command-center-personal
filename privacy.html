Privacy Policy

This Privacy Policy explains how Claire Command Center Personal (the “Application”) accesses and uses Google user data. The Application is a private, single-user tool operated for the account owner's personal use.

Google data accessed

Gmail read-only
https://www.googleapis.com/auth/gmail.readonly

Google Calendar read-only
https://www.googleapis.com/auth/calendar.readonly

The Application may access email messages, message metadata, mailbox information, calendar lists, and calendar events as needed to create personal summaries and support schedule awareness.

How data is used

Google user data is used only to provide personal-assistant functions requested by the account owner, including personal briefings, identifying time-sensitive information, and understanding upcoming personal calendar commitments.

The Application does not use Google user data for advertising, profiling for advertising, sale, or unrelated third-party services.

Read-only limitation

The Application does not request permission to send, modify, or delete Gmail messages. It does not request permission to create, edit, accept, decline, or delete Google Calendar events.

Data storage and security

OAuth credentials and any locally retained data are stored in private, access-restricted server storage. Access is limited to the account owner and the account owner's private assistant environment. Reasonable technical controls are used to prevent unauthorized access or disclosure.

Data sharing

Google user data is not sold. It is not shared with advertisers or data brokers. It is not disclosed to unrelated third parties except when required by law or necessary to protect the security of the account and service.

Retention and deletion

Data is retained only for as long as needed to provide the personal-assistant functions or maintain necessary personal records. The account owner may request deletion of locally stored Google-derived data and OAuth credentials at any time.

User control and revocation

The account owner can revoke the Application’s Google access at any time through the Google Account third-party connections settings. Revocation prevents future access. Locally stored OAuth credentials can also be deleted.

Changes

This policy may be updated if the Application’s functionality or data practices change. The effective date above will be updated when material changes are made.
