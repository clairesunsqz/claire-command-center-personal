# Claire Command Center Personal public pages

Static pages for the Google OAuth consent screen:

- `index.html` — application home page
- `privacy.html` — privacy policy

These pages intentionally contain no analytics, cookies, JavaScript, trackers, forms, or secrets.

Publish both files at the root of a public GitHub repository named `claire-command-center-personal`. Then use:

- Home page: `https://clairesunsqz.github.io/claire-command-center-personal/`
- Privacy policy: `https://clairesunsqz.github.io/claire-command-center-personal/privacy.html`
- Authorized domain: `clairesunsqz.github.io`
